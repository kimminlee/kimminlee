### 🚀 Key Project

#### **BEMS 3D Dashboard (건물 에너지 관리 시스템)**
> *3D 대시보드 UI 구현 및 CSV 데이터 시각화 프로젝트*

**Overview**
- 복잡한 에너지 흐름 데이터를 직관적으로 시각화하고, 비개발 직군도 쉽게 데이터를 관리할 수 있는 대시보드 구축.
- 기존의 레거시 UI를 **React + TypeScript** 기반의 컴포넌트 단위로 재설계하여 유지보수성 강화.

**Key Achievements**
* **데이터 핸들링 및 시각화**
    * DB 스키마와 불일치하는 외부 CSV 데이터를 클라이언트 단에서 파싱/변환하여 업로드하는 로직 구현.
* **UI/UX 최적화**
    * Viewport Unit(`vmin`)을 활용하여 해상도 비율(Aspect Ratio) 변화에도 UI 형태가 유지되는 **Fluid Layout** 구현.
    * 고딕 계열 폰트(Noto Sans)의 숫자 가독성 문제를 해결하기 위해 **Pretendard**로 전면 교체 및 타이포그래피 시스템 재정립.
* **생산성 향상**
    * **Vite** 기반 마이그레이션으로 빌드 및 HMR 속도 최적화.
